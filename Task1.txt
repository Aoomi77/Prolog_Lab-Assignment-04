1. ?- house = house.
Result: true.
Explanation: Both atoms are identical, so they unify.

2. ?- house = abc.
Result: false.
Explanation: The atoms are different, so they cannot unify.

3. ?- edge(a,b) = edge(C,b).
Result: C = a.
Explanation: C is unified with a.

4. ?- edge(a,d) = edge(C,B).
Result:
C = a,
B = d.
Explanation: C unifies with a and B unifies with d.

5. ?- edge(C,B) = edge(a,d).
Result:
C = a,
B = d.
Explanation: C unifies with a and B unifies with d.

6. ?- edge(A,f(g,h)) = edge(a,B).
Result:
A = a,
B = f(g,h).
Explanation: A unifies with a and B unifies with f(g,h).

7. ?- edge(A,A) = edge(b,c).
Result: false.
Explanation: The same variable A cannot be both b and c.

8. ?- edge(A,A) = edge(b,b).
Result: A = b.
Explanation: Both positions require A to be b, so they unify.

9. ?- A = B, B = f.
Result: A = B, B = f.
Explanation: A and B are linked, and B is unified with f.

10. ?- A = B, B = f, A = e.
Result: false.
Explanation: A and B must have the same value, so A cannot be e when B is f.
